# BRAVEN Store — New Project

واجهة متجر ملابس مستوحاة من التصميم المرجعي، مع متجر + سلة + Checkout + حساب + لوحة Admin.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد على GitHub Pages / Netlify / Vercel.

## لوحة الإدارة
افتح `admin.html`.
بيانات الدخول التجريبية:
- البريد: `admin@braven.com`
- كلمة المرور: `123456`

## ملاحظة مهمة
هذه النسخة Front-end تجريبية وتخزن المنتجات والطلبات في LocalStorage على نفس المتصفح. لا تستخدم بيانات الدخول التجريبية في متجر حقيقي. لعمل لوحة إدارة حقيقية وآمنة تعمل من أي جهاز، اربط المشروع بـ Supabase أو Backend مع Authentication وقاعدة بيانات.


## النسخة المجمعة
- سلة المشتريات وتعديل الكميات والحذف.
- حالة الطلبات والطلبات السابقة للمكتمل فقط.
- خصم المخزون عند إنشاء الطلب وإرجاعه عند الإلغاء.
- لوحة إيرادات تعتمد على الطلبات المكتملة مع اليوم والشهر والسنة ومتوسط الطلب والمقارنة وأعلى المنتجات.
- قوائم منفصلة للطلبات المكتملة والملغاة.
